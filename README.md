# Rock-paper-scissors-game
I have bulit this simple game which take inputs and user and also from computer using random function and gives output according to both the inputs 
 
## Features
- User input with case-insensitive choices.
- Random computer selection using Python's `random` module.
- Automatic winner and draw detection.
- Input validation for invalid choices.
- Simple and beginner-friendly code.

## Technologies Used
- Python 3
- `random` module
- Conditional statements (`if`, `elif`, `else`)
- User input and string methods
